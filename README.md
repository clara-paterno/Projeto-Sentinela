# Sentinela

Plataforma digital de comunicação e gerenciamento de ocorrências da Guarda Civil Municipal (GCM) de Piquet Carneiro, Ceará.

## Sobre o projeto

O Sentinela tem como objetivo facilitar a comunicação entre cidadãos e a Guarda Civil Municipal, permitindo o registro e acompanhamento de denúncias e ocorrências, além do gerenciamento dos atendimentos pelos agentes da GCM.
